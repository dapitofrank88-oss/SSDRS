The Secure Student Disciplinary Records System (SSDRS) is a web-based application designed to provide a secure, organized, and efficient way of managing student disciplinary records within an educational institution.

The system aims to simplify the recording, monitoring, updating, and management of student violations and disciplinary cases while maintaining the confidentiality and security of sensitive student information. It provides authorized administrators with tools to manage student records, monitor disciplinary case statuses, and generate disciplinary notices.

Students can also access their personal disciplinary records, view their recorded violations, check the status of their cases, and download official notices when available.

The project incorporates security features such as user authentication, email OTP verification, role-based access control, and account protection to help prevent unauthorized access to confidential information.

Through this project, MEDU-ISA (IT-35) aims to demonstrate how information technology can improve the efficiency, accessibility, accuracy, and security of disciplinary record management in educational institutions.
